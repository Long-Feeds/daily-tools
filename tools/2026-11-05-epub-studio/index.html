      流程

      1. 编码识别：先看 BOM，再按零字节分布判断 UTF-16，再试严格 UTF-8；都不是时，用 GB18030、Big5、Shift_JIS、EUC-KR、UTF-16、Windows-1252 各解一遍，按「常用字占比 − 非法序列惩罚」打分。常用字表不是手抄的，而是在页面里把 GB2312 一级字区、Big5 常用字区等码位现场解码生成的。
      2. 硬折行还原：统计行宽找出折行宽度 W（中日韩字符按 2 个半角宽）；一行之所以断在这里，是因为下一行的第一个词（或第一个汉字）放不下——满足这一条才接回去，所以诗句、对白这类本来就短的行不会被误接。
      3. 章节识别：第X章 / 回 / 节 / 卷、序章楔子番外、Chapter / Part、Markdown 标题，外加自定义正则。中文数字两种写法都认：「一百二十三」和古登堡本常见的逐位写法「一二三」「一〇〇」，也认廿、卅、两、大写数字。连续三个以上几乎没有正文的标题视为原书目录页并排除。
      4. 编号体检：同一层级里检查跳号、重复和回退（遇到新的一卷允许重新从 1 编号），正文过短的章节提示可能误判。
      5. 装订：mimetype 放第一个且不压缩，其余用浏览器原生 deflate 压缩；OPF 写 dcterms:modified、唯一标识、语言；同时生成 EPUB 3 导航文档与 EPUB 2 的 NCX；单个章节超过约 240 KB 自动拆成多个文件；所有文本按 XML 规则转义并去掉 XML 不允许的字符。

      体检规则

      「EPUBCheck 对应」一栏是把同一本书改坏后，分别交给本页和 W3C EPUBCheck 5.4.0 实测得到的代码。两处本页比它严：被压缩的 mimetype（OCF 规范写的是 MUST NOT）与 CRC 损坏，EPUBCheck 5.4.0 都不报，本页按规范报错。
