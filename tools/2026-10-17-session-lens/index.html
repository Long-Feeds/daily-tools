              计价公式

              成本 = (输入×P入 + 5m写×P5m + 1h写×P1h + 缓存读×P读 + 输出×P出) / 1,000,000 × 地域倍率 + 联网搜索次数 × $0.01

              每次 API 调用单独计价：快速模式（usage.speed = "fast"）先换成快速价，缓存倍率再叠在上面；usage.inference_geo = "us" 对 4.6 及之后的模型乘 1.1；Haiku 5.5 单次提示超过 100,000 token（输入 + 缓存读 + 缓存写）整次按高档计；Sonnet 4 / 4.5 超过 200,000 按 1M 上下文 beta 的历史高档计。所有金额先换算成 1e-10 美元的整数再相加，汇总顺序不影响结果。

              它怎么算

              Claude Code 把每个会话写成一份 JSON Lines：一行一条事件。本工具逐行解析，只保留算账需要的字段（截断后的提示、工具入参摘要、时间戳、用量），原文不进内存也不出本机。

              一次 API 调用 = message.id + requestId

              模型的一次回复会按内容块拆成多行写入，几行共用同一个 message.id 与 requestId，按它去重（与 ccusage 同口径）。子代理文件是流式写入的，前几行的 output_tokens 还没数完，只有最后一行是最终用量——本工具取最后一行。

              对账为什么常常对不上

              会话文件末尾的 cost-state 是 Claude Code 自己算的总账，它还包含不写进会话文件的后台调用（生成会话标题、各种分类器），所以“自报”通常比会话文件多几分钱，对账页会把多出来的部分按模型列出来。另一类差异来自 Claude Code 版本内置的价目：实测 2.1.284 把 Sonnet 5.5 的缓存读按 $0.20/MTok 计（官方价 $0.10），2.1.296 起与官方一致。

              时间都是推算的

              API 耗时 = 这次回复最后一行的时间 − 触发它的那一行（提示或工具结果）的时间；工具耗时 = 工具结果行 − 发出调用的那一行。并行工具会重叠，“工具累计耗时”是简单相加。

              回退的分支照样计费

              按 Esc 回退、或编辑之前的提示后，旧分支仍留在文件里。本工具从最后一个叶子沿 parentUuid 往回走（遇到压缩边界改走 logicalParentUuid），不在这条链上的调用标成“已回退”，它们的钱已经花了，照样入账。

              账本存什么

              每个会话按 15 分钟的 UTC 时间槽 × 模型 × 计价变体存一行 token 汇总（所有时区偏移都是 15 分钟的整数倍，换时区重新分桶不失真），以及标题、项目、起止时间。改价目后整本账自动重算。

              数据从哪来

              价目快照取自 Anthropic 官方价目页（2026-10-17）。开发时用本机 1,481 个真实会话做了两路对拍：与 Claude Code 自报逐模型 token 完全一致的 1,130 行里，769 行美元逐分一致、其余 361 行全部是上面那个 2.1.284 的缓存读价差；与 ccusage 按日按模型的 96 行 token 与美元全部一致。
