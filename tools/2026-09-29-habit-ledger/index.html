        备份与迁移

        JSON 可完整还原（含请假与每一条记录）；CSV 方便丢进表格。

        五种排程

        • 每天：从开始日期起每天都是应做日。
        • 每周指定几天：只有勾选的星期几是应做日（周一到周日）。
        • 每 N 天一次：开始日期当天、之后每隔 N 天是应做日，与星期无关。
        • 每周 N 次：周一到周日为一个周期，这一周里任意 N 天完成即算达标。
        • 每月 N 次：自然月为一个周期，任意 N 天完成即达标。

        什么算「完成」

        打勾型：勾上即完成。计量型：当天记录值 ≥ 目标值才算完成，没达标的部分记录照样保留、在热力图里显示成浅色。

        连续怎么算

        按日排程以应做日为单位、周期型以周期为单位，从最近一个往回数达标的个数，遇到第一个「漏打」停下：

        • 请假的应做日不计数、也不打断；周期型里请假的天会从可用天数里扣掉，所需次数 = min(N, 可用天数)，整期都请假就整期跳过。
        • 今天还没做不算漏打；本周 / 本月还没结束且没达标，也不算漏打。
        • 非应做日多做的一次会计入「累计完成」，但不影响连续。
        • 开始日期之前与未来日期的记录不计入任何统计。

        完成率

        近 N 天完成率 = 窗口内达标单位 ÷（达标 + 漏打）。周期型取与窗口有交集的周期；请假与尚在进行中的单位不进分母。没有可计分的单位时显示「—」。

        数据

        所有数据只写在本机浏览器的 localStorage 里，不上传。换设备请用「管理 → 导出 JSON」。
