QUANTUM CIRCUIT LAB

量子线路实验室。

在浏览器里搭一条量子线路，实时看到态向量、概率分布、布洛赫球和线路酉矩阵。支持中途测量、经典条件门与 OpenQASM 2.0 双向导入导出。零安装、零后端 —— 不用装 Qiskit，也不用注册任何账号。

线路编辑器

选一个门，再点线路图上的格子放下去。点已有的门可以删掉它。

读数

末态由线路的酉部分决定；测量与条件门在「测量」页里生效。

纠缠熵为 0 表示该比特处于纯态（与其余比特无纠缠）；为 1 表示它与其余部分最大纠缠，此时布洛赫矢量缩到球心。

OpenQASM 2.0

线路的文本形式。可以直接粘贴别处的 QASM 进来，也可以把这里的代码贴回 Qiskit。

支持的语法

OpenQASM 2.0 的一个子集，覆盖日常手写线路够用的部分。

写法含义
qreg q[3];声明 3 个量子比特
creg c[3];声明 3 个经典比特
h q[0];对单个比特作用门
h q;对整个寄存器广播
cx q[0],q[1];控制位在前，目标位在后
rz(pi/4) q[0];带参数的门，参数可写表达式
measure q[0] -> c[0];测量到经典位
reset q[0];把比特重置回 |0>
barrier q;栅栏（只影响排版）
if (c==2) x q[1];经典条件门
// 注释行注释与 /* 块注释 */

参数表达式支持 pi、四则运算、括号、^ 以及 sin / cos / tan / exp / ln / sqrt。导出时非 qelib1 标准的门会连同它的 gate 定义一起写出，方便别的工具直接加载。

数值口径

  • 比特序：小端。q0 是振幅下标的最低位，基态标签写作 |qn-1 … q1 q0>，与 Qiskit 一致。
  • 全局相位：保留。RZ 用 diag(e-iθ/2, e+iθ/2)，不是 diag(1, eiθ) —— 后者是相位门 P，两者只差全局相位，但在受控形式下差别是物理的。
  • 受控门参数序：控制位写在前面，目标位写在最后。三比特门同理，如 ccx q[0],q[1],q[2] 的目标是 q[2]。
  • 测量：会真的塌缩。中途测量后的经典位可用 if (c==V) 控制后续的门；「振幅 / 概率 / 布洛赫 / 酉矩阵」四个读数只看线路的酉部分，「测量」页才走完整的塌缩流程。
  • 结果分布：测量页同时给出采样频率和精确概率 —— 后者由穷举所有测量分支算出，不含采样噪声。
  • 本工具的引擎与 Qiskit 2.5 和 quantum-circuit 两套独立实现逐振幅对拍过（含全局相位）。

做不到的

  • 最多 10 个量子比特（态向量 1024 项）。再多在浏览器里就不合适了。
  • 没有噪声模型：不做退相干、门误差、读出误差，跑的是理想量子计算机。
  • 不支持 QASM 里的 gate 自定义门定义 —— 导入时会被跳过（名字若是内置门则静默忽略该定义）。也不支持 OpenQASM 3。
  • 酉矩阵视图只在 ≤ 4 比特时展示（16×16）；更多比特时矩阵有 2n×2n 项，看不过来。
  • 经典条件只支持「整个经典寄存器等于某个整数」这一种形式，这也是 OpenQASM 2.0 本身的限制。

怎么读布洛赫球

球面上的每一点是一个单比特纯态：北极 |0>、南极 |1>、赤道上是各种叠加态。当一个比特和别人纠缠时，它自己就不再是纯态了，矢量会缩进球内部 —— 缩到球心就是最大纠缠（贝尔态里的任一比特正是如此）。
