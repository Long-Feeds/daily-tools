它能做什么、不能做什么

做得到

  • ABC 记谱法与简谱互为输入，五线谱与简谱同时排版
  • 调号 7♯–7♭ 全覆盖，临时记号按「本小节内同音延续」的标准规则处理
  • 自动分小节、跨小节自动加延音线、按拍号分组连桁（6/8 按附点四分音符成组）
  • 连音符、附点、切分、弱起、反复与一二房子、和弦叠置、歌词、和弦记号
  • 整体移调并重写调号与音名拼写（不会写出 F♭♭ 这种）
  • 导出 MusicXML 4.0 / 标准 MIDI / SVG / PNG / ABC / 简谱文本

做不到（如实写在这）

  • 只排单声部单谱表：不做大谱表钢琴曲、不做多声部对位
  • 装饰音（{}）会被解析器跳过并给出提示，不参与排版与播放
  • 渐强渐弱、踏板、力度记号未实现
  • 播放是三角波合成音，不是采样音源；反复展开只处理简单的 |: :|
  • 不导入 MusicXML / MIDI（只导出）
