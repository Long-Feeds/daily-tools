口径、来源与验证

同一个指标在不同软件里常有不止一种口径。这里把本工具用的那一套逐条写明，方便你和手上的 Minitab / ReliaSoft / JMP 对表。

参数化

  • 威布尔：F(t) = 1 − exp(−((t−γ)/α)^β)，α 是尺度（特征寿命，F(α)=63.2%），β 是形状，γ 是位置。
  • 对数正态：μ、σ 定义在 ln t 尺度上，F(t) = Φ((ln t − μ)/σ)。
  • 伽马：α 为尺度、β 为形状，均值 = αβ。对数逻辑斯谛：F(t) = 1/(1 + (t/α)^(−β))。
  • 耿贝尔取最小值型（SEV）：F(t) = 1 − exp(−exp((t−μ)/σ))，均值 = μ − 0.5772σ。
  • 以上与 Python reliability 包 0.9 的参数化逐字一致，数值可直接互查。

似然与删失

  • 失效记 ln f(t)、右删失记 ln S(t)、左删失记 ln F(t)、区间删失记 ln(F(b)−F(a))。
  • 标准误来自自然参数空间的观测信息阵（负对数似然的数值海塞阵求逆）；正参数的置信区间走对数变换 p·exp(±z·SE/p)，与 reliability 一致。
  • AICc = AIC + 2k(k+1)/(n−k−1)，n 取全部记录数（含删失）。

中位秩与秩回归

  • 中位秩用贝纳德近似 (i−0.3)/(N+0.4)；有删失时先按平均秩序号法算调整秩：增量 = (N+1−上一个秩)/(1+本条及之后的剩余件数)。
  • RRX 回归 x 对 y（横向残差，可靠性行业默认），RRY 反过来。两者一般不相等。

系统与故障树

  • 框图按结构递归求解，表决门用泊松二项 DP，MTTF 由 ∫₀^∞ R(t)dt 自适应辛普森积分得到。
  • 故障树用 MOCUS 展开并做吸收得最小割集；顶事件概率是对最小割集做容斥的精确值（重复事件不会被重复计数），同时给出稀有事件近似与最小割集上界（MCUB）作对照。割集超过 20 个时只给上下界。
  • 重要度：富塞尔-维塞利 = 含该事件的割集并集概率 / 顶事件概率；伯恩鲍姆 = 把该事件钉成必然发生与必然不发生的顶概率之差；RAW、RRW 同源。

可用度

  • 生灭链稳态解用乘积式；平均正常时间 MUT 从系统刚修复回到的状态（n−k 台已失效）出发算首次到达时间，不是从「全好」出发 —— 用后者去凑 A = MUT/(MUT+MDT) 对不上稳态解。
  • 瞬态可用度由生成元矩阵的矩阵指数（缩放平方 + 13 阶帕德）给出。

可靠性增长与加速试验

  • Crow-AMSAA：E[N(t)] = λt^β，β̂ = n/Σln(T/tᵢ)；无偏修正定数截尾取 (n−2)/n、定时截尾取 (n−1)/n。拟合优度用 Cramér-von Mises。
  • 加速模型：阿伦尼乌斯 L = b·exp(a/S)（活化能 Ea = a·k_B）、艾林 L = (1/S)exp(−(c−a/S))、幂律 L = a·S^n、双应力指数 L = c·exp(a/S₁+b/S₂)；各应力水平共用一个形状参数，联合极大似然。
