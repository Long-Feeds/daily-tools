纯前端 · 零上传

把一段源码，从字符一路走到指令。

mini 是一门小而完整的语言：变量、函数、闭包、数组、循环。这一页里手写了它的词法分析器、Pratt 语法分析器、作用域与上值解析器、AST 优化器、字节码编译器和栈式虚拟机，并把每一步的中间产物摊开给你看——包括一个能下断点、单步执行、看操作数栈与调用帧的调试器。没有任何依赖库，代码不出浏览器。

mini 语言速查

      
let n = 10;            // 变量
fn add(a, b) {         // 函数
  return a + b;
}
fn counter() {         // 闭包
  let n = 0;           // 内层捕获外层的 n
  return fn () { n = n + 1; return n; };
}
let xs = [1, 2, 3];    // 数组
xs[0] = 9;
push(xs, 4);
if (n > 5 && !(n == 7)) {
  print("大");
} else {
  print("小");
}
while (n > 0) {
  n = n - 1;
  if (n == 3) { break; }
}
for (let i = 0; i < 3; i = i + 1) {
  print(i);
}

      
真值规则沿用 Lox：只有 nil 与 false 为假，0 和 "" 都为真。

  2. 语法分析：Pratt（自顶向下算符优先）解析表达式、递归下降解析语句，产出带源码区间的抽象语法树；出错会同步到分号后继续，一次报出多个问题。
    3. 
        
  3. 作用域解析：单趟编译中完成局部变量槽位分配与闭包上值捕获（沿词法链向外找，逐层登记 upvalue），顺带查出未定义变量、重复声明、循环外的 break。
    4. 
        
  4. 优化：在 AST 上做常量折叠、恒真/恒假分支消除、短路化简与不可达代码删除，并给出优化前后的指令数对比。
    5. 
        
  5. 代码生成：编译成栈式字节码，常量池 + 逐指令行号表；跳转用相对偏移回填。
    6. 
        
  6. 虚拟机：显式调用帧 + 操作数栈 + 开放/关闭上值链表；支持断点、单步、按行步进与运行时错误的调用栈回溯。
