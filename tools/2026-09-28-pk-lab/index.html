    模型

    线性乳突型房室模型：药物进出只经中央室（室 1），消除只发生在中央室，外周室与中央室以一级速率交换。微观速率常数 k10 = CL/V1、k1j = Qj/V1、kj1 = Qj/Vj。

    特征根 λ 是速率矩阵特征值的相反数：一室 λ = k10；二室解二次方程（小根用韦达定理 λ1·λ2 = k10·k21 回代，避免相减抵消）；三室用三角法解三次方程后逐根牛顿精修，最小根再用 λ1·λ2·λ3 = k10·k21·k31 回代。两个外周室回流速率恰好相同时，它们在中央室看来就是同一个室，自动精确并室。

    单位剂量静注响应 C(t) = Σ A_i e^(−λ_i t)，其中 A_i = Π(kj1 − λ_i) / Π(λ_j − λ_i) / V1。零级输注与一级吸收都是它与输入函数的卷积，写成闭式；一级吸收的核 (e^(−λt) − e^(−ka·t)) / (ka − λ) 总是提出较慢的那个指数再乘 expm1，ka 与某个 λ 相等时取极限 t·e^(−λt)。

    多次给药与稳态

    线性系统满足叠加原理：总浓度 = 每一次给药响应之和（负荷剂量、漏服、推迟、加倍都只是改给药事件表）。稳态把每个指数项的无穷级数求和成 1/(1 − e^(−λτ))，所以稳态曲线是闭式、不用「多给几十次等它收敛」。口服带滞后时间时按周期平移。

    读数口径：稳态峰、谷在一个间隔内用 400 格网格 + 黄金分割精修，并把输注结束、吸收起点这些折点单独列为候选；Cavg,ss = F·D/(CL·τ)，AUC24 = Cavg,ss × 24；蓄积比 R = 1/(1 − e^(−λz τ))；「达 90% 稳态」按末端相 ln10/λz 估算；峰谷波动 PTF = (Cmax,ss − Cmin,ss)/Cavg,ss。

    非房室分析（NCA）

    • 血管外给药与静滴若没有 0 时刻，补一个 (0, 0)；静注没有 0 时刻时用前两个正浓度点对数线性回推 C0（不下降就取首个观测值）。
    • AUC：「线性上升 - 对数下降」在浓度下降段用对数梯形，其余用线性梯形；AUMC 同一规则，对数段用 (t1C1 − t2C2)Δt/L + (C1 − C2)Δt²/L²，L = ln(C1/C2)。
    • λz 自动选点：候选为 Tmax 之后、浓度 > 0 的观测点，从最后 3 个起逐个往前加，只保留斜率为负的拟合；在最优校正 R² 的 0.0001 以内取点数最多的一组（与 Phoenix WinNonlin「Best Fit」口径一致）。Cmax 点不参与。
    • AUC0–∞ = AUClast + Clast/λz（用观测的 Clast）；外推占比超过 20% 时结果不可靠。MRT = AUMC∞/AUC∞，静滴再减 T/2；CL = Dose/AUC∞（血管外是 CL/F），Vz = CL/λz，静脉给药另给 Vss = CL·MRT。

    剂量设计

    • Cockcroft-Gault：CrCl = (140 − 年龄) × 体重 / (72 × SCr[mg/dL])，女性 × 0.85；μmol/L 除以 88.4 换成 mg/dL。理想体重男 50 kg、女 45.5 kg，身高每超过 60 英寸加 2.3 kg；校正体重 = 理想 + 0.4 ×（实际 − 理想）。「自动」口径：实际低于理想用实际，实际超过理想 120% 用校正，其余用理想。
    • Dettli：Q = 1 − fe × (1 − CrCl/正常 CrCl)（比值上限 1.5），剂量乘 Q 或间隔除以 Q。
    • Sawchuk-Zaske：τ = ln(峰/谷)/k + T，按 4/6/8/12/18/24/36/48 h 取最近的间隔，D = 峰 × k·V·T × (1 − e^(−kτ)) / (1 − e^(−kT))，按取整步长取整后再正算一遍预测峰谷；峰取在输注结束时刻。

    验证

    引擎与一份完全不同算法的 Python 真值逐项对拍（scipy expm 推进增广线性 ODE、周期仿射映射 (I − Φ)x0 = b 求稳态、numpy 另写一遍 NCA），另有一组不依赖任何实现的性质断言：ΣA = 1/V1、ΣA/λ = 1/CL、ΣA/λ² = Vss/CL²、稳态 AUCτ 的数值积分等于 F·D/CL、精确单指数数据上 NCA 给出解析值、密集采样的模拟曲线经 NCA 反推回 CL 与末端半衰期（含 flip-flop）。

    边界

    只覆盖线性（剂量无关）药代动力学：米氏饱和消除（苯妥英）、时间依赖清除、自身诱导、TMDD 都不在范围内。示例药物参数仅为示意量级，不能用来给真实患者定剂量——临床请以说明书、指南与临床药师的 TDM 为准。
