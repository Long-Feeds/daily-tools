    四种输入写法

    1 · 边表（最省事）

    前端 -> 网关 # 有向：左边指向右边 数据库 -- 缓存 # 无向 甲 -> 乙 8 # 末尾数字是权重 "带空格的名字" -> 乙 丙 # 单独一行 = 孤立节点

    2 · JSON

    {"nodes":["a","b"],"links":[{"source":"a","target":"b","weight":3}]} {"a":["b","c"],"b":{"c":2}} # 邻接表也认

    3 · DOT

    digraph G { a -> b [weight=2]; b -> c; c; }

    4 · 邻接矩阵

    ,甲,乙,丙 甲,0,1,0 乙,1,0,2 丙,0,2,0

    计算口径（重要）

    • 介数中心性：未归一化；无向图按惯例除以 2。加权版把权重当「距离」，无权版按跳数。
    • 紧密中心性：Wasserman-Faust 修正（乘以可达比例），有向图按入向距离。谐波中心性同样按入向。
    • PageRank：阻尼 0.85；出度为零的悬挂节点把分数均匀撒回全网。加权版按权重分配。
    • 特征向量中心性 / 聚类系数 / k-core / 割点 / 桥 / 最小生成树 / 二部判定：都在无向简单视图上算（去方向、去自环、反向平行边权重相加）。
    • 模块度 Q 与 Louvain：加权模块度；Louvain 用固定种子跑 12 次不同遍历顺序，取 Q 最大的一次，所以同一张图每次结果一致。
    • 最大流：权重当容量，无向边视作两个方向各有该容量。最小割是残量网络里源点侧割出来的边集。
    • 平行边：同方向重复的边会合并、权重相加；自环保留，但在无向简单视图里被忽略。

    上面每一项都拿 networkx 3.6 当权威实现对拍过：238 张图（含 6 份内置样例）× 全部指标 = 52463 个断言点，0 失配；解析器与三种打印格式另做了 2700 组随机往返测试。
