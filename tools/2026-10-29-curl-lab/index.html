          怎么保证「翻译得对」
          
          
            
          
            各语言运行时自带的请求头
            
          
            语言代码里没写也会发的头
            
          
            常见坑
            
          
              
            
            • curl 不认 --data=值 这种写法，也不认长选项缩写（--compress 会报 unknown）。
              • 
            
            • -d @file 会去掉文件里的回车换行，--data-binary @file 才原样发送。
              • 
            
            • URL 里的 [ ] { } 会被当成通配符：?a[b]=1 直接报错，要加 -g。
              • 
            
            • -H 'Cookie: …' 存在时，-b 给的 cookie 不会再发。
              • 
            
            • 多个 --json 直接首尾相接（不加 &），和 -d 混用时顺序决定有没有 &。
              • 
            
            • 请求体超过 1 MiB 时 curl 会加 Expect: 100-continue，先等服务器点头再发。
              •
