    这个工具算了什么，没算什么

    房间声学的工程计算基本就是这么几件事：把吸声量加起来估混响、把箱体的简正解列出来看驻波、用镜像声源法把早期反射逐条摆出来、再用阻抗传递算吸声构造。这一页把它们串成一条链，改任何一个输入，后面全跟着变。

    引擎口径

      对拍了什么

      —

      • pyroomacoustics 0.10.1 —— 镜像声源的坐标、阶数、衰减逐条对拍；脉冲响应逐样本对拍；T30/T20 把同一条脉冲响应喂给它的 measure_rt60 交叉核对。
      • acoustics 0.2.6 的 iso_9613_1_1993 —— 大气吸收系数与声速。
      • scipy eigsh —— 把房间离散成三维 Neumann 拉普拉斯矩阵直接解特征值，与解析模态公式毫无共享代码；细网格误差约为粗网格的四分之一，正是二阶收敛该有的样子。
      • scipy solve_ivp（DOP853） —— 把分层介质的一维波动方程从刚性壁往外数值积分，与传递矩阵代数是两条独立路径。
      • 不依赖任何实现的物理性质 —— Sabine ≥ Eyring ≥ Millington（后者由 Jensen 不等式保证）、镜像声源与模态响应的互易性、全吸声墙时 SBIR 恒为 0 dB、λ/4 共振位置、Weyl 模态计数渐近律、C50 与 D50 的恒等式、处理方案回代。

      一个花絮：第一轮对拍时吸声构造 480 例里红了 480 例，查下来是我写的那个数值积分 oracle 错了 —— 它从刚性壁往外积分却没给积分变量换向，解出来的表面阻抗实部是负的（等于说墙面在往外发声）。页面这一侧的被动性断言 Re(Zs) > 0 反而一直是对的。

      已知的简化

      • 只支持长方体房间。有斜顶、凹凸、隔断的房间，模态与镜像声源都不再适用。
      • 镜像声源法假设墙面镜面反射、不做扩散；真实房间的后期混响比这里更密、更平滑。阶数上限也会把尾巴截断，所以脉冲响应页的 T30 通常比「房间与混响」页的统计公式短。
      • 吸声构造按局部反应之外的扩展反应算（层内按斜入射波数传播），但不含边缘绕射 —— 真实混响室测出来的 α 常常大于 1，本页不会。
      • 材料表是典型值，63 Hz 与 8000 Hz 是外推。做正经项目请用厂家的 ISO 354 实测报告。
      • 模态求和用刚性壁的简正函数、阻尼按 T60 折算，低频定性对、定量只作参考。

      常见问题

      为什么两页算出的混响时间对不上？

      「房间与混响」页是统计声学公式（假设声场扩散、能量均匀），「脉冲响应」页是逐条镜像声源叠出来的确定性模拟并且阶数有限。两者本来就不该完全相等，差异大小本身就是「这个房间够不够扩散」的一个信号。

      Sabine、Eyring、Millington 该看哪个？

      平均吸声系数小于 0.2 时三者差不多，随便哪个都行。吸声一多，Sabine 会系统性偏长；此时看 Eyring。各面吸声差别很大（比如只有天花做了吸声）时，Millington 更接近实际，但它对接近 1 的 α 很敏感。

      数据会上传吗？

      不会。整页是一个静态 HTML，所有计算都在你的浏览器里完成，参数只存在 localStorage 和你自己复制的分享链接里。
