为什么不重编码

普通剪辑软件导出时要把每一帧解码再重新压缩：慢、发热、画质再掉一层。这里只改「索引」，码流原样拷贝。

秒级

几 GB 也是秒出

只重写几十 KB 的 moov 索引，媒体数据直接按原字节拼接，浏览器把文件切片引用进结果，不复制、不占内存。

逐帧

两种切法

兼容模式把起点吸附到关键帧，任何播放器都认；精确模式保留关键帧做解码前置、用编辑列表把多余帧藏起来，起止精确到帧。

隐私

抹掉拍摄地点

手机视频常带 GPS 坐标（©xyz / loci / Apple ISO 6709）。导出时可只删定位，或连设备型号、拍摄时间一并清除。

最近剪辑

剪辑方案按文件指纹自动保存在本机；重新打开同一个文件，片段会自动恢复。

    纯本地

    文件用浏览器的 File / Blob 切片读取，结果也是切片拼出来的 Blob，没有任何网络请求。

    能处理什么

    MP4、MOV、M4A、3GP，含分片 MP4（OBS、录屏常见）；视频 H.264 / HEVC / AV1 / VP9 等，音频 AAC / Opus / MP3 / FLAC / ALAC / PCM。加密（DRM）文件不支持。

    做不到什么

    不重编码就不能加字幕、调色、改分辨率；兼容模式下起点只能落在关键帧，想精确到帧请用精确模式。
