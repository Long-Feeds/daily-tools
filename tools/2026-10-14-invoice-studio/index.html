        写法依据

        按中国人民银行《支付结算办法》附件「正确填写票据和结算凭证的基本规定」。

        1. 到「元」为止的写「整」；有角无分的，角后不写「整」；有分的不写「整」。
        2. 数字中间有 0 时写「零」，连续多个 0 只写一个「零」：1,409.50 → 壹仟肆佰零玖元伍角。
        3. 角位是 0、分位不是 0 时，「元」后必须写「零」：16,409.02 → 壹万陆仟肆佰零玖元零贰分。
        4. 万位、元位是 0 而千位、角位不是 0 时，可写一个零也可不写；本工具取不写：107,000.53 → 壹拾万柒仟元伍角叁分。
        5. 拾位开头写「壹拾」，防止被改写：10.00 → 壹拾元整。
        6. 不足一元的，直接从角分写起：0.05 → 伍分。
