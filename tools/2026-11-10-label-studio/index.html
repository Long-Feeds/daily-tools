            [+] 选哪种码
            
          
              
            
            • [+] EAN-13 / UPC-A：超市收银扫的商品条码。号码要向 GS1（国内是中国物品编码中心）申请，自己编的号进不了商超系统。
              • 
            
            • [+] Code 128：店内 SKU、仓库库位、快递单号、亚马逊 FBA 标签（X00 开头的 FNSKU）。本工具按最少码字自动切换 A/B/C 码集，同样内容条码最短。
              • 
            
            • [+] GS1-128：物流箱、医药、食品追溯，括号里的数字是应用标识符：(01) 商品码、(17) 有效期、(10) 批号、(00) 箱码 SSCC。
              • 
            
            • [+] ITF-14：纸箱外箱，印刷质量差也能扫；四边保护框防止扫描线从侧面漏读。
              • 
            
            • [+] Data Matrix：同样内容比 QR 小，适合小零件、医疗器械 UDI、药品追溯；支持中文（UTF-8 + ECI）。
              • 
            
            • [+] QR：手机扫码、网址、中文说明。
              • 
            
            • [+] Code 39 / Codabar：老系统、图书馆、血站常见；Code 39 只认大写，要小写就打开「全 ASCII」。
              • 
          
            
        
            
        
            
          
            [+] 打印要点
            
          
              
            
            • [-] 打印对话框选 实际大小 / 100%，页边距 无；缩放会让条宽和标签位置都错。
              • 
            
            • [-] 热敏机（203 dpi）一个点 0.125 mm：模块宽最好是整数个点，打开「打印机点阵」会自动对齐，并告诉你放大系数变了多少。
              • 
            
            • [-] 喷墨或碳带会把条「印胖」：在「条宽缩减」里每条减掉 0.01–0.03 mm。
              • 
            
            • [-] 不干胶整张没用完：在「打印」页点格子选起始位置，从第一个空位接着印。
              • 
            
            • [-] 先勾「印出标签边框」用普通纸试印一张，对着光和标签纸叠一下，偏多少就在「校准」里补多少。
              • 
          
            
        
            
      
            
      
            
        
            
          
            [+] 引擎怎么做的
            
          
              
            
            • [x] Code 128：动态规划在 A/B/C 三个码集与 Shift 之间找码字最少的走法，同长时少切换。
              • 
            
            • [x] EAN/UPC：左半按首位数字选奇偶字符集，UPC-E 由校验位和数制决定奇偶，2/5 位附加码按 GS1 规则算奇偶。
              • 
            
            • [x] Data Matrix ECC200：ASCII / C40 / Text / Base256 四种编码最短分段，数据末尾按符号容量决定能否省掉换回码；GF(256)（本原多项式 301）里德-所罗门纠错，按 ISO/IEC 16022 附录 F 摆放，24 种正方形 + 6 种长方形尺寸。
              • 
            
            • [x] GS1：45 个常用 AI + 310n–337n、390n–393n 带小数位的 AI；校验位、YYMMDD 日期（DD=00 表示只到月）、字符集 82、预定义长度表决定哪里需要 FNC1 分隔。
              • 
            
            • [x] 版面：一份毫米几何同时供屏幕预览、SVG/PNG 导出和打印使用，打印走浏览器原生 @page，真尺寸出图。
              • 
          
            
        
            
        
            
          
            [+] 隐私
            
          
            所有编码、排版、打印都在这个页面里完成；模板和数据只存在本机浏览器（localStorage），不会上传。
