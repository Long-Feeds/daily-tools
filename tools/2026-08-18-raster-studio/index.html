关掉一个平面会发生什么

裁剪判据在齐次坐标里只是六个不等式。把它们逐个关掉试试：只关近平面往往看不出差别（w < 0 的顶点同样过不了侧向那两条不等式），六个一起关掉，1/w 才会把相机背后的几何翻到画面上、当场撕开 —— 这就是「忘了裁剪」的事故现场。

RASTER STUDIO

一页纸的软件渲染器。写它是为了把「图形学第一课」的每个抽象名词 —— 齐次坐标、视锥裁剪、重心插值、深度缓冲 —— 变成可以拖动、可以关掉、能立刻看见后果的东西。

  • 模型 → 世界 → 视图
  • 投影 → 齐次裁剪
  • 透视除法 → 视口
  • 背面剔除 → 光栅化
  • 深度测试 → 着色
