DER · BER

ASN.1 结构树

左边是结构树（↑↓ 移动、←→ 折叠展开），右边是对应的字节： 标签与长度   内容 。OCTET STRING / BIT STRING 里包着的 DER 会自动展开（紫色标注）。

    PATH VALIDATION

    验证证书链

    贴服务器实际下发的证书（叶子 + 中间证书）。会自动找出叶子、理顺顺序、到信任库里找根，逐级验签名、有效期、CA 资格、路径长度、密钥用途与名称约束。

    填好左边，点「验证」。也可以在「解析」页选中一张证书后点「验证这条链」。

    ISSUE

    本地签发

    密钥由浏览器的 WebCrypto 生成，不会上传。适合本地开发 HTTPS、内网服务、mTLS 联调；公网网站请用公共 CA。

    KEYS

    密钥格式转换与配对

    贴私钥或公钥（也可以连证书一起贴，用来检查是不是一对）。支持 PKCS#8、PKCS#1、SEC1、SPKI、加密 PKCS#8。

    贴一把密钥，这里列出所有格式（PEM / DER / JWK / OpenSSH）与公钥指纹。

    EXPIRY

    TROUBLESHOOT

    TLS 报错翻译

    把 curl、openssl、浏览器、Go、Java、Node、Python 报的证书错误原样贴进来，看它到底是什么意思、该怎么修。

    贴一段报错试试。

    REFERENCE

    常见报错一览

    根证书：curl 从 Mozilla certdata.txt 提取的 TLS 根证书库（），随页面内置，验证时不联网。

    验签用浏览器 WebCrypto：RSA（PKCS#1 v1.5 / PSS）、ECDSA P-256 / P-384 / P-521、Ed25519。SHA-1 / MD5 签名、1024 位 RSA 会被标为不可信，和现代浏览器一致。

    不做的事：不在线查询 OCSP / CRL、不处理 PKCS#12 容器、不检查证书策略树。私钥只在你主动勾选「保存 CA」时才写入本机 localStorage。
