怎么用

  1. 在「图纸」页拖入图片（或点示例）。像素画会自动识别放大倍数，直接按原始像素出图纸。
  2. 设宽度（颗）、选品牌色卡；颜色太多就设上限，照片可开抖动让过渡更自然。
  3. 用画笔 / 填充 / 吸管 / 橡皮修细节；色号清单里点一行可高亮这一色、并设为画笔颜色。
  4. 「预览与施工」页按拼板逐块施工、勾进度、算缺口；「色卡与库存」页记库存、查别家色号。

颜色是怎么配的

每格颜色先在 sRGB → 线性光 → CIE XYZ（D65，x = 0.3127，y = 0.3290）→ CIELAB 里表示，再用 CIEDE2000（kL = kC = kH = 1）找色卡里最近的豆子。找最近色时按明度排好序，从目标明度往两侧找，剩下的豆子明度差一旦大到不可能更近就停（下界 ΔE00 ≥ |ΔL|/1.75），结果与逐个比对完全相同，只是快得多。

颜色上限：先把每种格色配到最近的豆子，再一色一色地淘汰「拿掉后总色差增加最少」的那一色，直到剩 K 色；最后做 PAM 式交换（集合里任一色换成色卡里任一色，能降总色差就换），直到换不动为止。这是局部最优、不保证全局最优：在 300 组小规模随机实例上与穷举最优对拍，295 组命中最优，最差的一组总色差多 4.2%。

抖动：在所选色差公式的颜色空间（Lab / OKLab）里做误差扩散，蛇形扫描；只在有豆子的格子之间传误差，强度可调。

去背景：取图纸四边一圈格子的 Lab 逐通道中位数当背景色，从四边出发、四连通、ΔE76 ≤ 容差的格子整片去掉。杂色清理：同色四连通块面积不够的，并进与它共享边最多的邻色（并列时取更像的那一色）。

数据与口径

色卡来自开源项目 maxcleme/beadcolors（MIT 许可，提交 —）：MARD 291 色、Perler 103 色、Perler Mini 41 色、Hama Midi 92 色、Hama Mini 78 色、Artkal S 199 色、Artkal C 174 色、Yant 119 色、Nabbi 30 色。颜色是社区实测的近似值，不是厂商官方值；不同批次、灯光、屏幕都会让实物与屏幕有差别，重要作品请先对照实物色卡。

豆子规格只用来算成品尺寸（宽 × 颗距）；拼板尺寸只用来分块，请按你手上的板子选。

隐私

图片解码、配色、导出全部在你的浏览器里完成，不上传任何服务器。图纸、库存、设置存在本机 localStorage，清除浏览器数据会一起清掉，换设备前请用「我的图纸 → 导出全部」备份。
