      导出子集 网页字体减重

      网页只用到几十个字，却让访客下载十几兆的中文字体 —— 子集化就是只留下用到的那些字形，重写 glyf / loca / cmap / hmtx， 再打包成 TTF 或 WOFF。整个过程在本地完成，licensed 的字体不用上传给第三方网站。

      子集里留下了什么

      本页自己解析 sfnt：head / hhea / maxp / hmtx / OS-2 / post / name / cmap(0,4,6,12,13,14) / loca / glyf / CFF / kern / GPOS / GSUB / fvar / avar / gvar， 轮廓、度量、字距、可变插值都逐条与 fontTools 的读数对拍过；导出的子集也由 fontTools 复核过轮廓与字符映射。

      做不到的部分照实说：WOFF2 需要 Brotli 解码（浏览器没开放该接口），CFF/CFF2 轮廓的字体可以看但暂不支持导出子集， GSUB 只跑单字替换与连字，导出的子集不携带 GSUB / GPOS 布局表。

      字体文件全程留在浏览器内存里，没有任何上传。
