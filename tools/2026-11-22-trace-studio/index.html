它在做什么

            
先把图片变成黑白（或按颜色分成几层），再由 Potrace 把每块黑色的边界描成贝塞尔曲线。曲线只描边界，所以放大多少倍都清晰。

            
    
              
  • logo / 图标：黑白或彩色分层，预放大 2× 让小图边缘更顺。
    • 
              
  • 扫描线稿：用「自适应」阈值对付阴影和泛黄纸张，加大去斑点。
    • 
              
  • 像素画：打开「像素精确」，每个像素都是正方形，放大不糊。
    • 
              
  • 切割 / 激光：导出 DXF（毫米，闭合多段线），或 SVG「仅轮廓」。
    •

HOW IT WORKS

    
Potrace 的五步

    
Peter Selinger 2003 年的算法：先找出像素边界，再求一个「最少边数」的多边形贴住它，然后把顶点挪到最优位置、按夹角决定圆滑还是尖角，最后把能合并的曲线合并。

    
    
      
  1. 01 · decompose拆路径沿黑白交界走一圈得到闭合路径，孔洞按「谁在谁里面」挂成树；面积不到阈值的斑点直接丢弃。
    2. 
      
  2. 02 · polygon最优多边形对每个点求「还能一笔直线走多远」，再用动态规划挑边数最少、偏离最小的多边形。
    3. 
      
  3. 03 · adjust挪顶点把每个顶点放到相邻两条最小二乘直线的「交点」，但不许离开原来那个像素格。
    4. 
      
  4. 04 · smooth圆滑或尖角按顶点偏离程度算 α：超过「拐角」阈值留尖角，否则换成一段三次贝塞尔。
    5. 
      
  5. 05 · opticurve合并曲线同向弯曲、总转角小于 179° 且误差在容差内的相邻曲线，合成一段。
    6.
