      怎么算的

      说明

      这里写清楚题是怎么数、怎么抽的，竖式和脱式按什么规矩写，错因怎么认出来。

      「一共几道」是精确数出来的

      加减法用数位动态规划：从个位往高位逐位填数，状态里记着「有没有进位、已经进了几次、每个数跟上下界比是小 / 等 / 大」。这样「两位数加两位数、恰好进位一次、和不超过 100」这种条件能直接数出精确个数，再按个数加权一位一位抽，保证每道符合条件的题被抽中的机会一样。减法 a − b 当成 b + 差 = a 来数：哪一位要退位，正好就是加回去时哪一位满十。

      不重复、可复现

      符合条件的题不多时先全部列出来，再按种子洗牌取前 N 道；题很多时抽到重复就重抽。同一个种子、同样的设置，永远是同一张卡——分享链接里带着种子，别人打开看到的是同一张。

      竖式按课本写法

      • 加减法相同数位对齐，进位写在横线上方前一位，退位点写在被借的那一位上面；
      • 乘数是多位数时逐位乘出部分积、末位与该位对齐；因数末尾有 0 先把 0 前面的数对齐、最后添 0；
      • 除法商写在被除数相应数位上，不够商 1 就商 0，余数后面添 0 继续除；除数是小数先化成整数。

      错因是怎么认出来的

      拿孩子写的数去对几种典型错法：逐位相加但没进位、不够减时倒过来用大数减小数、退位后忘了减 1、口诀邻近的积、部分积没错位、试商偏大 / 偏小、商中间漏写 0、分母也相加、没通分、没约分、没先乘除后加减、没先算括号……对得上就说出是哪一种，对不上才只说「算错了」。

      进位怎么数

      加法里每一次「满十进一」都算一次进位，最高位进上来的 1 也算。乘法（多位数乘一位数）里，进位要被加进更高一位的乘积才算一次；最高位乘出的几十直接写下，不算进位——所以 52 × 3 算「不进位」，25 × 4 算「进位一次」。

      脱式计算的顺序

      有括号先算括号里面的（小括号在里、中括号在外），几个括号互不相干就同时算；没有括号时先算乘除，再从左往右算加减，几段乘除互不相干也同时算——和课本「能同时算的同时算」一致。所有记录、错题、题卡都只存在浏览器的本地存储里。
