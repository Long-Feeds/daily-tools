    添加后会出现在景深、视角、星空页的快捷按钮里。

      计算口径

      每个数字都来自下面这些式子；所有计算在本机完成，器材与设置只存在浏览器里。

      曝光

      EV100 = log₂(N²/t) − log₂(ISO/100)。照度换算用入射式测光的 ISO 2720 口径，校准常数 C = 250，即 E = 2.5 × 2EV 勒克斯。名义档位按 1/3 档吸附；比较时用名义值本身（f/5.6 而不是 5.657）。场景 EV 是常见参考值，实际以测光为准。

      ND 与闪光

      减光档数 = log₂(倍数) = 光密度 × log₂10（ND1000 约 9.97 档，OD 3.0 同理）。有效闪光指数 = GN × √(ISO/100) × √功率，最远距离 = 有效 GN / 光圈。

      景深

      薄透镜精确式：近点 = f²s / (f² + Nc(s − f))，远点 = f²s / (f² − Nc(s − f))，分母不为正时远点为无穷远；超焦距 H = f²/(Nc) + f。距离 d 处的弥散直径 b = f²|s − d| / (N·d·(s − f))。弥散圆 c 默认取传感器对角线的 1/1500（全画幅约 0.029 mm），也可换成蔡司的 1/1730、2 倍像素间距或自定义。艾里斑直径 = 2.44 λ N(1 + m)，λ = 550 nm。

      视角

      视角 = 2·arctan(尺寸 / 2f)，按对焦无穷远计；画面覆盖尺寸 = 传感器尺寸 × (s − f) / f。等效焦距、等效光圈都乘以裁切系数（全画幅对角线 ÷ 本机对角线）。

      星空

      • 500 法则：t = 500 / (f × 裁切系数)，只看焦距，高像素机身上会明显拖尾。
      • NPF 简化式：t = (35N + 30p) / f，p 为像素间距（µm），f 为实际焦距；按需除以 cos δ。
      • 按像素拖尾：恒星日 86164.0905 秒，把画面中心的星点方向绕天极转过 ωt，再用针孔模型投影回像平面，位移除以像素间距得像素数（小角度时约等于 f·ωt·cos δ / p）；对它二分求根即「不超过 k 像素」的最长曝光。
      • 星轨弧长 = 总时长 × 360° / 恒星日。
