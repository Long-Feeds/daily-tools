口径与出处

这一页说明每个数字是按哪一套口径算的、引擎和谁对拍过、以及哪些地方不能当设计依据。

计数

雨流计数

三点法照 ASTM E1049-85 §5.4.4 逐条实现：栈里取最近三点，X ≥ Y 就把 Y 记一次， 含起点时记半循环；跑完剩下的残余全部按半循环记。

四点法照 ISO 12110-2 / Amzallag：|S2−S1| ≤ |S1−S0| 且 ≤ |S3−S2| 时闭合中间那一对。 残余接上自己再数一遍，就是「重复历程」口径，结果全是整循环。

反向点提取把首末点都算作反向点，连续相等的点跳过（平台取最后一个下标）。

对拍：三点法与 python 包 rainflow 3.2.0 逐字段（幅值/均值/计数/两个下标）一致； 四点法与 fatpack 0.7.8 的 find_rainflow_cycles + concatenate_reversals 一致； 8 条内置谱 + 140 条随机谱全部逐条比过。

S-N

S-N 曲线与损伤

EN 1993-1-9：ΔσC 定在 2×10⁶，m=3 到 5×10⁶（ΔσD = ΔσC·(2/5)^⅓），m=5 到 10⁸（ΔσL = ΔσD·(5/100)^⅕），之后截止。 FAT 90 因此给出 ΔσD = 66.3、ΔσL = 36.4，与规范表一致。

口径：EC3 / IIW 用应力范围 Δσ，Basquin 与振动疲劳文献用应力幅 σa。 页面上每处都写明用的是哪一个，引擎内部不做隐式换算。

平均应力修正（等效全反向幅 σar）：Goodman σa/(1−σm/Su)、Gerber σa/(1−(σm/Su)²)、 Soderberg 用 Sy、Morrow 用 σf′、SWT √(σmax·σa)、Walker σmax^(1−γ)·σa^γ（γ=0.5 时就是 SWT，γ=1 等于不修正）。 默认对压平均应力不做修正（保守），可在左栏打开。

对拍：曲线的 N(S)/S(N) 与 fatpack 的 Linear / BiLinear / TriLinear 耐久曲线一致； Miner 和与 find_miner_sum 一致；四种等效应力与 fatpack.stresscorrection 一致。

Marin

耐久限与缺口

Se = ka·kb·kc·kd·ke·Se′，Se′ 取 0.5Su（钢，Su ≤ 1400 MPa）或 0.4Su（铝）。 ka = a·Su^b 按表面加工取 (a,b)；kb 用旋转弯曲的 1.24d^−0.107 / 1.51d^−0.157； kc 弯曲 1 / 轴向 0.85 / 扭转 0.59；kd 按温度表插值；ke = 1 − 0.08·z。

缺口：Peterson q = 1/(1+a/r)、Neuber q = 1/(1+√a/√r)，Kf = 1 + q(Kt−1)。 Neuber 法则 (Kf·S)²/E = σ·ε 配 Ramberg-Osgood ε = σ/E + (σ/K′)^(1/n′) 解局部应力应变； 另给 Glinka 应变能密度法则作对照（它给出的局部应力总是不高于 Neuber）。

ε-N 用 Coffin-Manson-Basquin：εa = σf′/E·(2Nf)^b + εf′·(2Nf)^c，平均应力走 Morrow 或 SWT。 材料的 K′、n′ 由 σf′/b/εf′/c 导出（n′ = b/c，K′ = σf′/εf′^n′），保证四个参数自洽。

验证：这一页没有第三方库可对拍，改用两类断言 —— ①各准则线上的安全系数必须恒等于 1、 Neuber 解必须精确满足 σ·ε = (Kf·S)²/E、应变寿命解回代必须还原输入； ②ka(690, 机加工)=0.798、kb(32)=0.858、ke(99%)=0.814 等公开算例的点值。

断裂

裂纹扩展的几何与适用范围

  • 无限宽板中心裂纹：K = σ√(πa)，精确解。
  • 有限宽板中心裂纹：Feddersen 正割式 Y = √sec(πa/W)，适用 2a/W ≤ 0.7。
  • 单边裂纹拉伸：Tada 多项式，适用 a/W ≤ 0.6（a→0 时 Y → 1.1215 的自由表面值）。
  • 圆形（钱币）裂纹：K = (2/π)σ√(πa)，精确解。
  • 内部椭圆裂纹最深点：Irwin 精确解 K = σ√(πa)/E(k)，k² = 1−(a/c)²；a/c=1 时退化为钱币裂纹。
  • CT 试样：ASTM E647 的 f(α) 多项式，适用 α ≥ 0.2。

速率律：Paris C·ΔK^m、Walker（把 ΔK 换成 ΔK/(1−R)^(1−γ)）、Forman（含 (1−R)Kc−ΔK 的分母， 自带 Kc 渐近）。门槛可开关，开时 ΔK < ΔKth 不扩展。

验证：等幅寿命与 scipy.integrate.quad 对同一个被积函数独立积分一致（90 个几何×律×载荷组合）； Y=1 的 Paris 情形另有闭式解；变幅积分器在等幅谱上必须退化到闭式解； 椭圆形状因子逐点对拍 scipy.special.ellipe。

变幅扩展按雨流循环逐个施加，不含过载迟滞/裂纹闭合等相互作用效应 —— 真实变幅谱下这类效应可能显著，这里只给无相互作用的基线。

谱方法

频域方法

Welch 谱：Hann 窗（周期型）、50% 重叠、逐段去均值、单边密度定标 —— 与 scipy.signal.welch(window='hann', detrend='constant', scaling='density') 逐点一致。

谱矩按圆频率加权 m_i = ∫(2πf)^i G(f) df，于是 m₀ = 方差、ν = √(m₂/m₀)/2π、νp = √(m₄/m₂)/2π、 α_i = m_i/√(m₀·m_2i)。十种方法：窄带（Rayleigh）、Dirlik、Tovo-Benasciutti（1989 与 2005 两版）、 Wirsching-Light、Ortiz-Chen、α₀.₇₅、单矩法、Zhao-Baker（法 1、法 2）。

对拍：12 条形状各异的谱 × 4 组 (C,k) × 10 种方法与 FLife 一致， 概率密度也逐点对过。一处分歧：Zhao-Baker 法 2 的定标方程在宽带谱上可能没有正实根， FLife 用 fsolve 从 0 出发不收敛却照样返回一个数；这里改用解析三次根， 无正根时直接标「不适用」而不给假数。

别当设计依据

材料数据与免责

材料库里的 Su/Sy/σf′/b/εf′/c 与 Paris 的 C/m/Kc/ΔKth 都是教材典型值（Shigley、Dowling、 Barsom-Rolfe 那一档量级），只为让工具开箱能跑；每个数都可以在左栏改。 真实设计必须用自己那一批材料、那一种工艺、那一个环境下的试验数据。

内置载荷谱除「ASTM E1049 教科书序列」外全部是固定种子合成的，不是实测记录； 它们只用来演示方法差异。
