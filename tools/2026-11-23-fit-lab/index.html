我的拟合

数据、模型、参数设置与上次的结果一起存在本机浏览器（localStorage），不上传。

怎么算的

非线性模型：Levenberg–Marquardt 信赖域法，逐函数移植 MINPACK 的 lmder / lmpar / qrfac / qrsolv / enorm（Moré 1980，scipy curve_fit 与 leastsq 用的就是它），雅可比来自对公式的符号求导而不是差分。收敛后再做至多 4 步高斯–牛顿精修：最小二乘步在双倍精度（double-double，约 32 位有效数字）里解；只含加减乘除与整数幂的有理模型，残差也在双倍精度里求值，只接受不让残差平方和变大的步。

线性模型（对参数线性，如多项式、a + b*ln(x)）：自动识别，不迭代、不需要初值，基函数在双倍精度里求值后做 Householder QR。十次多项式 Filip 的 11 个系数因此能对上 NIST 认证值约 14 位；在普通双精度里求基函数只有 7–8 位。

上下界：与 lmfit 相同的 MINUIT 变换（两侧有界用 sin，单侧用 √(θ²+1)），协方差在原参数空间按雅可比计算；落在边界上的参数会标出来，它的标准误不可信。

统计量的口径

  • 协方差 = s²·(JᵀWJ)⁻¹，s² = SSR/(n−p)（χ²ᵣ）。σ 选「绝对误差」时不乘 s²（等同 scipy absolute_sigma=True）。
  • t = 估计值 / 标准误，p 为双侧，置信区间 = 估计值 ± t₍₁₋α/₂, n−p₎·标准误。
  • R² = 1 − SSR/SST，SST 按（加权）均值中心化；对参数线性且没有常数项的模型（如 b*x）改用非中心化 SST = Σwy²，与 R 的 lm()、NIST 口径一致。
  • logLik、AIC、BIC 按 R 的 logLik.nls：含残差方差这一个参数，k = p + 1；AICc = AIC + 2k(k+1)/(n−k−1)。
  • 置信带 = ŷ ± q·√(gᵀCg)，q 取 t 分位（逐点）或 √(p·F₍p, n−p₎)（同时，Scheffé：整条曲线的均值同时被罩住）。g 是 ∂f/∂p。
  • 预测带 = ŷ ± t·√(gᵀCg + σ²ₙₑw/m)，总是逐点（Scheffé 管不了任意多个新观测）。σ²ₙₑw 取 s²（等权或相对权重，按权重 1 的新观测计）；σ 选「绝对误差」时取 1。反算用同一个 σ²ₙₑw。
  • 反算：在数据 x 范围内密扫 f(x) − y₀ 的变号、二分到机器精度，不变号的切点用黄金分割找 |f − y₀| 的极小；候选根要验残差（极点两侧的变号不算根）。区间取 y₀ 落在预测带里的那段 x（逆回归），delta 法 SE = √(gᵀCg + σ²ₙₑw/m)/|f′(x̂)| 并列给出。
  • Durbin–Watson 按 x 排序后的（加权）残差计算；游程检验看残差符号，游程太少（p 小）说明曲线系统性偏离数据。

已知限制

  • Lanczos1 的认证残差平方和是 1.4×10⁻²⁵，低于双精度求模型值的噪声，RSS 与标准误只能对上 3 位左右（参数仍有 10 位以上），R、scipy 也一样。
  • NIST 的 Rat43 文件印的自由度是 9，按它给的残差标准差反推应为 11（= 15 − 4），本页按 11 计。
  • 非线性拟合可能停在局部极小。换几个初值或点「多起点搜索」（在参数量级附近随机撒 48 个起点各跑一遍，取残差最小者）。
  • 只支持一个自变量 x；NIST 的 Nelson（两个自变量）未收录。
