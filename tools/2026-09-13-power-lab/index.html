潮流计算

电压稳定裕度

PV 鼻子曲线

经济调度与静态安全

λ 迭代求等微增率解（可外层套交流潮流刷新网损），再用直流灵敏度做 N-1 全扫描：PTDF 是注入-潮流灵敏度，LODF 把「断哪条线、别的线涨多少」一次算清。

等微增率

每台机的边际成本曲线与最终的系统 λ。未触限的机组必然都落在同一条水平线上 —— 这就是经济调度的全部内容。

N-1 静态安全校核

逐条支路开断，用 LODF 推算全网潮流。「解列」表示该支路是唯一通路，断了就有母线失电。

口径、语法与验证

元件语法

BASE <基准容量 MVA> BUS <号> [SLACK|PV|PQ] [PD=] [QD=] [GS=] [BS=] [KV=] [VMAX=] [VMIN=] [V=] [NAME=] GEN <母线> [P=] [Q=] [V=] [QMIN=] [QMAX=] [PMIN=] [PMAX=] [C2=] [C1=] [C0=] [XD=] [X2=] [X0=] [OFF] LINE <f> <t> R= X= [B=] [RATE=] [R0=] [X0=] [B0=] [OFF] TRAFO <f> <t> R= X= [TAP=] [SHIFT=] [RATE=] [R0=] [X0=] [CONN=] [OFF] SHUNT <母线> [G=] [B=]
  • PD QD P Q QMIN QMAX PMIN PMAX RATE 是有名值（MW / Mvar / MVA）。
  • R X B GS BS XD X2 X0 是系统基准下的标幺值；TAP 是挂在 from 侧的变比，SHIFT 单位为度。
  • C2 C1 C0 是二次发电成本 C = C2·P² + C1·P + C0 的系数（元/MW²h、元/MWh、元/h）。
  • CONN 取 YNyn / Dyn / YNd / YNy / Dd / Yy，决定零序通路。
  • 没写类型的母线，挂了在运机组就按 PV 处理；没有 SLACK 时自动指定一条。

数值口径

  • 支路模型与 MATPOWER 完全一致：Ytt = ys + jb/2、Yff = Ytt/(tap·tap*)、Yft = −ys/tap*、Ytf = −ys/tap，其中 tap = 变比·e^{j·移相角}。
  • 无功越限按整条母线的机组合计判断（pandapower 按单台机判，两种口径在多机母线上会给出不同结果）。
  • 短路用经典对称分量法、故障前电压可选平启动或潮流解；不是 IEC 60909（后者带电压系数 c 与阻抗修正，数值会略高）。
  • 零序默认值：线路 R0=3R、X0=3X、B0=0.5B；变压器 X0=X1；发电机 X2=Xd″、X0=0.5·Xd″ 直接接地；没写 XD= 的机组按 0.25 pu 处理并在结果里提示。
  • 某条母线在零序网里没有接地通路时，单相接地电流取解析极限 0，两相接地退化为两相短路。
  • PTDF / LODF / N-1 建立在直流模型上（忽略电阻与无功），与交流潮流的结果会有差别，用途是快速排序而非精算。

交付前的对拍

引擎在发布前跑过一套离线对拍，共 121646 条断言、0 失配。参照来自四套互不相干的实现：

  • pandapower 3.5.4（Python / PYPOWER 血统）—— 265 个算例 × 交流潮流的电压、相角、两端支路潮流、网损。
  • GridCal（独立 Python 实现）—— 同样 525 次潮流，最大偏差 2.3×10⁻¹⁰。
  • PowSyBl OpenLoadFlow / pypowsybl 1.16.1（法国 RTE 的 Java 实现）—— 不含母线电导的 125 个算例，最大偏差 2.1×10⁻¹¹。
  • numpy 裁判 —— 直接按 MATPOWER 支路模型算功率残差，谁满足方程谁对；scipy SLSQP 校经济调度；闭式解校短路。

对拍过程中反过来发现了参照实现的三处问题，都以规范原文或边界条件为准：

  • PowSyBl 的 MATPOWER 导入器不认母线电导 GS：140 个含 GS 的算例最大偏差 9.2×10⁻³，而 125 个不含 GS 的算例偏差 2.1×10⁻¹¹。
  • GridCal 在网络含移相变压器时会把参考角设成移相角（解相同，整体旋转了一下），按平衡节点对齐后一致。
  • GridCal 的不对称短路不满足故障点边界条件：2 母线例上单相接地算出的故障点 Va ≈ 0.667 而非 0，故未采用；改以链式网络的闭式解为准（52,316 条断言）。

它不做什么

  • 不做暂态稳定与机电暂态仿真，只算稳态。
  • 不做最优潮流（OPF）；经济调度不含网络约束，安全性由 N-1 扫描另行校核。
  • 只支持单平衡节点、单一同步区；多区域互联与直流输电未建模。
  • 短路只算次暂态阶段的工频分量，不含直流分量衰减与非周期分量。
