关于这个工具
PDF 的解析、解密、文字还原和导出全部由这个页面手写实现，零依赖、零上传：交叉引用表与交叉引用流、对象流、六种流过滤器（Flate 的 inflate 是页内手写的 RFC 1951 实现）、PNG/TIFF 预测器、简单字体与 CID 字体的编码与 ToUnicode、内嵌 Type1 / TrueType / CFF 字体程序里的内建编码，以及 RC4 与 AES-128/256 的标准安全处理程序。

发布前的对拍：引擎在 400+ 份真实 PDF 上与 pypdf / poppler(pdftotext)逐页比对，过滤器与摘要算法与 Python 的 zlib / hashlib / cryptography 随机对拍。
