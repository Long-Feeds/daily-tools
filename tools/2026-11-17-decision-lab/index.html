方法与口径

同一个方法在不同教材与开源库里常有细节差异，下面逐条写明本页采用的口径与对拍结果。

1. 正向化（只对中间型、区间型，或选了「先正向化」的成本型）

中间型（最优值 t）：M = max|xᵢ − t|， yᵢ = 1 − |xᵢ − t| / M （M = 0 时全为 1） 区间型（最优区间 [a, b]）：M = max(a − min x, max x − b) xᵢ < a：yᵢ = 1 − (a − xᵢ)/M； a ≤ xᵢ ≤ b：yᵢ = 1； xᵢ > b：yᵢ = 1 − (xᵢ − b)/M 成本型：默认不转换，由各方法按「越小越好」处理；也可先做 max − x 或 1/x，之后一律当效益型。

两种成本型处理会给出不同的 TOPSIS 数字：国际文献与 pymcdm 在方法内处理（向量规范化后成本列取 1 − r），清风数学建模教程先做 max − x 再规范化。论文里写清用的是哪一种即可，本页两种都支持。

2. AHP 层次分析法

特征向量法：A·w = λmax·w（幂迭代到 1e-16），λmax 取主特征值 几何平均（方根法）：wᵢ ∝ (Πⱼ aᵢⱼ)^(1/n) 算术平均（和积法）：wᵢ = (1/n)·Σⱼ aᵢⱼ / Σₖ aₖⱼ 后两种的 λmax = (1/n)·Σᵢ (A·w)ᵢ / wᵢ（与 pyDecision ahp_method 相同） CI = (λmax − n)/(n − 1)，CR = CI / RI，CR < 0.1 视为通过；n ≤ 2 恒一致 层次总排序：CR总 = Σ w组·CI组 / Σ w组·RI组
  • RI 表有三套，教材之间常混用：Saaty 1980 经典表（n=3…15：0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45, 1.49, 1.51, 1.48, 1.56, 1.57, 1.59，同 pyDecision）；Saaty 2005《ANP》p.31（0.52, 0.89, 1.11, 1.25, 1.35, 1.40, 1.45, 1.49, 1.52, 1.54, 1.56, 1.58, 1.59，同 AHPy 的 saaty 选项）；Donegan & Dodd 1991（AHPy 默认）。也可以填自己教材上的数。
  • 修正建议：对每个上三角判断，把 17 档标度逐一换进去重算 CR，每格取最好的一档，列出改后 CR 最低的三格。只改一处，尽量保留原判断。
  • 两层结构：在数据页给指标填「准则层」名称即可，先比较准则层，再比较组内指标，全局权重 = 准则权重 × 组内权重。

3. 客观赋权

熵权法：pᵢⱼ = yᵢⱼ / Σᵢ yᵢⱼ，eⱼ = −Σᵢ pᵢⱼ ln pᵢⱼ / ln m（0·ln0 = 0），dⱼ = 1 − eⱼ，wⱼ = dⱼ / Σ d y 取「极差标准化」或「原值（成本型取倒数，同 pyDecision entropy_method）」 CRITIC：按方向极差标准化；σⱼ 样本标准差；Cⱼ = σⱼ·Σₖ(1 − rⱼₖ)；wⱼ = Cⱼ / Σ C 变异系数法：vⱼ = sⱼ / x̄ⱼ（原始数据，要求均值为正）；标准差法：极差标准化后的 σⱼ 归一 组合：线性 w = α·w主 + (1 − α)·w客；乘法 w ∝ w主·w客

常数列（所有方案取值相同）：标准化结果记为 1（同 pymcdm），熵为 1、权重为 0；CRITIC 里它与其他列的相关系数按 0 计（同 pyDecision）。

4. 七种评价方法

加权和 SAW：Sᵢ = Σⱼ wⱼ·rᵢⱼ（r 可选极差 / 比例 / 比重 / 向量标准化） TOPSIS：vᵢⱼ = wⱼ·rᵢⱼ；v⁺ = 列最大，v⁻ = 列最小；Cᵢ = D⁻ᵢ / (D⁺ᵢ + D⁻ᵢ) VIKOR：Sᵢ = Σ wⱼ(f*ⱼ − fᵢⱼ)/(f*ⱼ − f⁻ⱼ)，Rᵢ = max 同项，Qᵢ = v(Sᵢ − S*)/(S⁻ − S*) + (1 − v)(Rᵢ − R*)/(R⁻ − R*) 折中解：C1 Q(a₂) − Q(a₁) ≥ 1/(m − 1)；C2 a₁ 在 S 或 R 上也最好（Opricovic & Tzeng 2004） 灰色关联：Δᵢⱼ = |x₀ⱼ − xᵢⱼ|，ξᵢⱼ = (Δmin + ρΔmax)/(Δᵢⱼ + ρΔmax)，γᵢ = Σ wⱼ ξᵢⱼ PROMETHEE II：π(a, b) = Σ wⱼ Pⱼ(dⱼ)，φ⁺ = Σ π(a, ·)/(m − 1)，φ⁻ = Σ π(·, a)/(m − 1)，φ = φ⁺ − φ⁻ EDAS：PDA / NDA 以列均值为基准，AS = (SP/max SP + 1 − SN/max SN)/2 COPRAS：Qᵢ = S⁺ᵢ + (min S⁻·Σ S⁻)/(S⁻ᵢ·Σₖ min S⁻/S⁻ₖ)，Uᵢ = Qᵢ / max Q

PROMETHEE 的阈值 q、p、s 按「该指标极差的倍数」填写，页面换算成原始单位。分数相等（相对差 ≤ 1e-12）记同名次，名次按「1, 2, 2, 4」计。

5. 对比、共识与敏感性

  • Spearman ρ：对平均秩求 Pearson 相关；Kendall τ-b：带并列修正。共识名次按各方法的平均名次；Borda 分 = Σ(m − 名次)；Copeland 分 = 两两对决赢的场数 − 输的场数。
  • 权重扫描：把一个指标的权重设为 t，其余指标按原比例分配 1 − t；第一名变化的位置用二分法精确到 1e-12。
  • SMAA：用 mulberry32 伪随机数，均匀模式按 −ln(1 − U) 归一得到单纯形上的均匀权重；保持排序模式把抽到的权重按当前权重的大小顺序重排；整体可接受度 = Σ 排名概率 ×（m − 名次）/(m − 1)。

6. 与开源库的口径差异（对拍时逐条核过源码）

  • pymcdm 1.4.0 的 COPRAS 写成 Sp + (min(Sm)·Sm)/(Sm·(min(Sm)/Sm))，漏了两个 Σ，化简后等于 S⁺ + S⁻——成本型指标越大得分越高。本页按原始公式，与 pyDecision 一致。
  • pymcdm 的 VIKOR 在所有方案的 R（或 S）相同时出现 0/0，结果全是 NaN；本页把这一项记为 0。
  • pymcdm 的熵权 只要某列出现 0，就把这一列的熵直接置 0（权重被推到最大）；本页按 0·ln0 = 0 只跳过那一项。它的 CRITIC 也不区分指标方向，成本型列的相关系数符号会反过来。
  • pyDecision 的 PROMETHEE II 不看方向（成本列要先取负）；灰色关联度多除了方案数 m；VIKOR 在 C1、C2 都不满足时返回全部方案。
  • AHPy 的权重默认四舍五入到 4 位小数；它的 saaty 选项是 2005 年的 RI 表，与多数中文教材引用的 1980 表不同。

7. 验证

引擎与 pymcdm 1.4.0、pyDecision 5.1.8、scikit-criteria 0.10、AHPy 2.1、numpy / scipy 逐项对拍：7 套离线对拍共 111,397 项全部一致——AHP 13,308 · 客观赋权 18,836 · 七种评价方法 41,836 · 正向化 6,159 · 排名与相关 17,000 · 敏感性与 SMAA 2,662 · 性质检验（列缩放不变、方案置换等变）11,596。对拍过程中还抓出并修掉了一处 VIKOR 的浮点退化问题：S 或 R 理论上全相等时，1e-17 级的舍入噪声会被放大成整档的名次差。

顺带的发现：pymcdm 1.4.0 的 COPRAS 在 865 个含成本型指标的算例里有 833 个与 pyDecision 结果不同，其中 757 个连名次都不同。
