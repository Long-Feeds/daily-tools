看清 Parquet 的
每一个字节

打开一个 .parquet：schema、行组、列块、数据页、编码与压缩一层层摊开。预览与导出数据，模拟查询引擎的谓词下推，给文件做体检，比较不同编码的体积，或把 CSV / JSON 写成 Parquet。Snappy、GZIP、ZSTD、LZ4 都在本页里解压，文件不上传。

打开文件

拖一个 .parquet 到这里，或点按钮选择。大文件只读 footer 与你点开的列块，几百 MB 也能秒开结构。

格式依据 apache/parquet-format（parquet.thrift、Encodings.md）与 RFC 8878（ZSTD）、RFC 1951 / 1952（DEFLATE / GZIP）、Snappy 与 LZ4 块格式说明。读取结果逐单元格对拍过 pyarrow 26 与 DuckDB 2.0，写出的文件由 pyarrow、DuckDB、fastparquet 读回核对。

不支持：BROTLI / LZO 压缩（会如实报错）、加密 Parquet、ALP 浮点编码。schema 快照与偏好只存在本机 localStorage，文件内容不保存、不上传。
