这一页在做什么

整条链路都是这一页自己算的，没有任何后端和第三方库：

  • SMILES 解析器——有机子集原子、方括号原子（同位素 / 电荷 / 显式氢 / 原子映射）、四种键型、分支、双位环号 %nn、. 分隔的多组分。
  • 环感知——对每条键找最小环，再在 GF(2) 上做线性无关筛选，得到 SSSR。
  • Kekulé 化——按化合价判断哪些芳香原子需要一根双键，然后在芳香子图上做回溯完美匹配。
  • 芳香性判定——逐环数 π 电子（稠合体系内的双键算在体内），套 4n+2；单环不满足时再试稠合子集的并集（薁就是这么判出来的）。
  • 规范化——Morgan 式不变量迭代细化 + 逐次打破简并，再按规范序 DFS 输出。
  • 坐标生成——环系用正多边形拼装并按已放好的原子拟合定位，随后做位置投影松弛（干净的环系整体当刚体，只许平移旋转），最后逐条非环键旋转支链消拥挤。
  • 制图——纯 SVG：键线按标签盒收缩、双键在环内侧偏置、杂原子带氢与电荷排版。
  • 质谱——按元素同位素分布做二进制幂卷积并剪枝，合并到单位分辨率。

数值口径

  • 原子量用 IUPAC 标准原子量，同位素质量与丰度取自 NIST（经 RDKit 与 molmass 两份数据交叉核对）。
  • 精确质量按电荷扣除电子质量（0.000549 Da/电荷）。
  • TPSA 用 Ertl 2000 拓扑极性表面积法，只计 N/O（与 RDKit 默认口径一致）；参数表共 33 种原子环境。
  • HBD / HBA 用 Lipinski 定义：HBA = N 与 O 的个数，HBD = 连在 N、O 上的氢的个数。
  • 可旋转键 = 非环、非共轭端点的单键，两端重原子度均大于 1 且都不带叁键（RDKit 的 NonStrict 口径）。
  • 环数 = SSSR 环秩 = 键数 − 原子数 + 组分数。注意金刚烷按这个口径是 3 而不是 4——4 是「对称化 SSSR」的说法。

做不到的

  • 立体化学不参与计算：@ / @@ 与 / \ 能被解析（不会报错），但规范化输出与结构图里会被丢弃，手性异构体算出来是同一个。
  • 桥环笼状体系（降冰片烷、立方烷、金刚烷、吗啡）没有等键长的平面嵌入，画出来是近似投影，可能有交叉。
  • 不做互变异构 / 共振式归一化，也不做 N-氧化物之类的电荷分离改写：O=n1ccccc1 与 [O-][n+]1ccccc1 会被当成两个不同的输入。
  • 不解析 SMARTS、不做子结构匹配、不算 logP。
